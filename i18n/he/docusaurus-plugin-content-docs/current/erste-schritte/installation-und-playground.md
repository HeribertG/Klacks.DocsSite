# התקנה ו-Playground

את Klacks אפשר לנסות תוך דקה - ולהתקין תוך דקות ספורות. ללא הרשמה, ללא שיחות מכירה.

## Playground: מגרש המשחקים להיכרות

ה-Playground אינו אפשרות התקנה, אלא מופע Klacks ציבורי עם נתוני דוגמה למשחק חופשי וללא התחייבות - מכאן השם. הוא פועל בכתובת **[play.klacks-software.ch](https://play.klacks-software.ch)**:

- **התחברות:** `admin@test.com` · **סיסמה:** `P@ssw0rt1`
- יש לכם הרשאות מנהל מלאות - נסו הכול.
- נתוני הדוגמה כוללים כ-5,000 לקוחות והם נתוני הדגמה בלבד.
- **אין להזין נתונים אישיים אמיתיים.** מסד הנתונים מאופס מדי יום בשעה 04:00 שעון שווייץ (02:00 UTC) למצב קבוע.

## התקנה: על השרת שלכם (On-Premise)

חבילת ה-On-Premise כוללת הכול: תמונות Docker, מתקין, מסד נתונים, HTTPS ועדכונים אוטומטיים. אתם מורידים אותה אך ורק ב-[Klacks Store](https://klacks-software.ch/store/?culture=he).

ב-Klacks Store בחרו לפי הצורך את הענף שלכם והורידו את קובץ ה-ZIP של המדינה שלכם. המתקין יוצר בעצמו סיסמאות ותעודות, טוען את תמונות ה-Docker העדכניות וממתין עד שהכול פועל.

### Linux: צעד אחר צעד

תצטרכו מחשב עם לפחות 8 GB של RAM, פורטים 80 ו-443 פנויים, גישה לאינטרנט וחשבון עם הרשאות `sudo`. אין צורך ש-Docker יהיה מותקן מראש (ראו שלב 4).

1. **הורידו את ה-ZIP מ-Klacks Store.** בעמוד של המדינה שלכם ב-[Klacks Store](https://klacks-software.ch/store/?culture=he), לפי הצורך עם הענף שלכם.
2. **חלצו לתיקייה קבועה**, למשל `~/klacks`, ולא ל-`Downloads` או ל-`/tmp`. העדכונים האוטומטיים יעבדו בהמשך בדיוק עם תיקייה זו; אם היא נמחקת או מועברת, הם נשברים. המתקין מזהיר אם הוא רץ מ-`Downloads` או מ-`/tmp`.

   ```bash
   unzip 'klacks-onprem-*.zip' -d ~/klacks
   ```

3. **פתחו טרמינל בתיקייה.** במנהל הקבצים זה אפשרי בדרך כלל בלחיצה ימנית בתוך התיקייה (שם הפעולה תלוי בסביבת שולחן העבודה), או שאתם מקלידים `cd ~/klacks`.
4. **הפעילו את המתקין:**

   ```bash
   sudo bash ./install-de.sh
   ```

   בחבילה של גרמניה הסקריפט נקרא `install-de.sh`; בחבילות של מדינות אחרות קוד המדינה מופיע בשם, כלומר באופן כללי `sudo bash ./install-*.sh`. המתקין זקוק ל-`sudo` כדי שיוכל לפנות ל-Docker ולהתקין אותו בעת הצורך. בלי `sudo` זה עובד רק אם Docker כבר מותקן והמשתמש שלכם שייך לקבוצה `docker`.

   **אם Docker חסר**, המתקין מציע להתקין את Docker Engine באמצעות הסקריפט הרשמי מ-`get.docker.com`. זה קורה רק לאחר שאלה אליכם (`[y/N]`, ברירת המחדל היא לא) ורק ב-Ubuntu, Debian, Fedora, CentOS ו-RHEL; לשם כך המחשב צריך `curl` או `wget` וגישה לאינטרנט. בהפצות אחרות התקינו בעצמכם את Docker Engine עם תוסף Compose לפי [המדריך של Docker](https://docs.docker.com/engine/install/). אם המתקין רץ ללא טרמינל, `INSTALL_DOCKER=yes` עונה על השאלה בכן. Docker עצמה אינה ממליצה על סקריפט זה לשימוש בייצור; לשרת ייצור התקינו את Docker בעצמכם. `docker-compose` הישן (גרסה 1) אינו נתמך, נדרש התוסף `docker compose`.
5. **המתינו.** המתקין יוצר סיסמאות ותעודה בחתימה עצמית, טוען את התמונות ומפעיל את ה-Stack. בהפעלה הראשונה ה-API מבצע מיגרציה של מסד הנתונים; המתקין ממתין לכך עד עשר דקות. בסוף מופיע `Klacks is up at https://…` ומתחתיו **קוד ההגדרה שלכם** (`Your setup code`, שנים-עשר תווים בשלוש קבוצות של ארבעה). רשמו אותו; הוא נמצא גם בקובץ `.env` בתיקיית ההתקנה בשם `KLACKS_SETUP_CODE`.
6. **פתחו את Klacks:** `https://localhost` (בשם שרת אחר או בפורט HTTPS אחר - הכתובת מהודעת המתקין). הדפדפן מזהיר מפני התעודה בחתימה עצמית; אשרו את האזהרה. לאחר מכן יוצרים באמצעות קוד ההגדרה את חשבון המנהל שלכם, ראו [ההתחברות הראשונה](#first-login).
7. **עדכונים** מתבצעים לאחר מכן אוטומטית באמצעות שירות העדכונים המובנה. אין צורך להפעיל את המתקין שוב לשם כך.

אם Docker רואה פחות מ-7 GiB של זיכרון, התקנה ראשונה נעצרת. כיצד מגדירים מארח קטן יותר מוסבר ב[דרישות המערכת](../betrieb/systemvoraussetzungen.md).

### Windows

תחת Windows הפעילו `install-*.ps1` במקום `install-*.sh`.

### אפשרויות: שם השרת ופרופיל המדינה

עם פרופיל מדינה אופציונלי המתקין מגדיר בהפעלה הראשונה מיד שפה, חגים, גבולות שעות עבודה, תוספות ותבניות ענפים:

```bash
sudo SERVER_NAME=klacks.example.com REGION=de bash ./install.sh
```

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -ServerName klacks.example.com -Region de
```

ב-Linux המשתנים באים **אחרי** `sudo`: `sudo` בדרך כלל אינו מעביר למתקין משתנים שמופיעים לפניו. עם הסקריפט של חבילת המדינה הקריאה נראית כך: `sudo SERVER_NAME=klacks.example.com bash ./install-de.sh`.

חבילת המדינה מ-Klacks Store מכילה את הפרופיל של המדינה שלה. הסקריפטים `install-*.sh` ו-`install-*.ps1` שבחבילה כבר מגדירים את `REGION` או `-Region` לקוד המדינה שלה - בחבילה של גרמניה למשל `install-de.sh` ו-`install-de.ps1`. אם קוראים ישירות ל-`install.sh` או ל-`install.ps1`, חייב `REGION` או `-Region` להיות קוד המדינה הזה; בלעדיו המתקין אינו מגדיר פרופיל מדינה.

## מחשב משרדי עם Windows: גם ב-Microsoft Store

למחשב משרדי יחיד עם Windows קיימת תוכנת התקנה נפרדת שפועלת ללא Docker. ניתן לקבל אותה ב-[Klacks Store](https://klacks-software.ch/store/?culture=he) בעמוד של המדינה שלכם וגם ב-[Microsoft Store](https://apps.microsoft.com/store/detail/XPFFW8HDX0KX26) (הערך "Klacks"). בשתי החנויות זו אותה תוכנת התקנה. בהתקנה מ-Microsoft Store היא מחילה את המדינה שמוגדרת ב-Windows; שם אינכם בוחרים ענף, ואם אין פרופיל למדינה זו, ההתקנה אינה מגדירה פרופיל. התקנות על שרת, ב-Docker וב-Linux, וכן חבילות המדינות והענפים, זמינות רק ב-Klacks Store.

במחשב המשרדי גרסאות חדשות מגיעות דרך הגדרות > [עדכוני תוכנה](../einstellungen/system-sicherheit/updates.md) ב-Klacks, גם אם Klacks הותקן מ-Microsoft Store. לא ניתן להתקין תוכנת התקנה חדשה יותר מעל התקנה קיימת.

## ההתחברות הראשונה: חשבון המנהל שלכם {#first-login}

ל-Klacks שהותקן זה עתה עדיין אין חשבון שלכם. לכן בפתיחה הראשונה בדפדפן מופיע מיד העמוד "הגדרת חשבון המנהל שלך", עוד לפני כל התחברות: שם פרטי ושם משפחה, כתובת דוא"ל (היא תהיה שם ההתחברות שלכם) וסיסמה, שמוזנת פעמיים; כללי הסיסמה מוצגים בזמן אמת לצדה.

בשרת (Docker) העמוד דורש בנוסף את **קוד ההגדרה**, גם אם אתם פותחים את Klacks בדפדפן על השרת עצמו. את הקוד הציג המתקין בסוף ההתקנה; הוא נמצא גם בקובץ `.env` בתיקיית ההתקנה בשם `KLACKS_SETUP_CODE`. הוא תקף רק להגדרה אחת זו. קוד שגוי נדחה ("קוד ההגדרה אינו תואם. בדקו אותו ונסו שוב.").

ברגע ששומרים, החשבון שלכם מקבל את תפקיד המנהל וחשבון הבדיקה המצורף מושבת סופית באותה פעולה; לאחר מכן Klacks מחבר אתכם אוטומטית עם החשבון שלכם; אם זה נכשל, התחברו עם פרטי הגישה החדשים. כל עוד מוגדר קוד הגדרה, אי אפשר בכל מקרה להשתמש בחשבון הבדיקה המצורף להתחברות בדפדפן. אחר כך מופיע העמוד "מדינה וענף".

עד שחשבונכם נוצר, השרת חוסם כל פנייה נוספת עם קוד השגיאה `SETUP_REQUIRED` (HTTP 403). אין מאחורי זה תקלה: חסרה רק ההגדרה.

- במחשב משרדי עם Windows אינכם צריכים קוד הגדרה אם אתם פותחים את Klacks בדפדפן על אותו מחשב. ממחשב אחר מופיע רק עמוד ההתחברות.
- אם Klacks מציג במקום זאת את עמוד ההתחברות, למשל בהתקנה ללא קוד הגדרה, פלט המתקין מציין את החשבון המצורף; גם אז Klacks מוביל אתכם ישירות ליצירת חשבון המנהל שלכם.
- אם שני אנשים שולחים בו-זמנית, רק הראשון הופך למנהל; השני מגיע לעמוד ההתחברות.

רק ב-Playground ובסביבת פיתוח מקומית שער זה מושבת בכוונה; שם החשבון המצורף נשאר.

## כדאי לדעת

- **דרישות:** לפחות 8 GB של RAM ו-4 vCPU, Docker עם Compose v2 (ב-Linux המתקין מתקין את Docker לאחר שאלה), פורטים 80 ו-443 פנויים וגישת HTTPS יוצאת אל `ghcr.io` ו-`github.com`. פרטים ודוגמאות חישוב למארחים קטנים יותר ב[דרישות המערכת](../betrieb/systemvoraussetzungen.md).
- שירות עדכונים מובנה שומר על ההתקנה שלכם עדכנית באופן אוטומטי - עם גיבוי לפני כל עדכון ושחזור אוטומטי במקרה של בעיות. כיצד זה מתנהל בפירוט מוסבר ב[עדכונים ושחזור](../betrieb/updates-und-rollback.md).
- הנתונים שלכם נמצאים במסד הנתונים שלכם על התשתית שלכם. עם זאת, חלק מהפונקציות פונות לשירותים חיצוניים - אילו, מפורט בסעיף הבא.
- הפעלה חוזרת של המתקין אינה מזיקה, אך אינה עדכון: הוא שומר על הסיסמאות, התעודה והגרסה שנקבעה בהתקנה הראשונה ומפעיל מחדש את ה-Stack (ב-Linux שוב עם `sudo`, אם התקנתם תחילה עם `sudo`). כך מתקנים Stack שהפסיק לעבוד. גרסאות חדשות מתקין שירות העדכונים, לא המתקין.
- אם יש לכם תעודה משלכם, הניחו את `server.crt` ו-`server.key` לפני ההתקנה ב-`nginx/certs/` בתיקיית ההתקנה; אחרת המתקין יוצר תעודה בחתימה עצמית.
- את מסד הנתונים שלכם אתם מגבים בעצמכם באופן קבוע - כיצד, מוסבר ב[גיבוי ושחזור](../betrieb/backup-und-wiederherstellung.md).

## אילו שירותים חיצוניים Klacks קורא

הנתונים שלכם נמצאים על השרתים שלכם. עם זאת, לחלק מהפונקציות Klacks פונה בהפעלה הרגילה לשירותים ציבוריים באינטרנט. כתובות השירותים האלה מוטמעות בקוד; כרגע אי אפשר להזין שרת גיאוקידוד, ניתוב או מפות משלכם.

| שירות | לשם מה | מה נשלח | ברירת מחדל | כיבוי |
|---|---|---|---|---|
| Nominatim של OpenStreetMap (`nominatim.openstreetmap.org`) | המרת כתובות לקואורדינטות: בשמירת כתובת, למיקום החברה, בתכנון מסלולים ובשירותי רקע לכתובות ולמיקומי קבוצות | רחוב, מיקוד, עיר ומדינה, ללא שמות של אנשים; במיקומי קבוצות שם המקום או הקבוצה | פעיל | `BackgroundServices__AddressGeocoding=false` ו-`BackgroundServices__GroupGeocoding=false` מכבים רק את שירותי הרקע. בשמירת כתובת עדיין מתבצע גיאוקידוד. |
| שרת OSRM הציבורי (`router.project-osrm.org`) | זמני נסיעה, מרחקים ומסלולים במפה | קואורדינטות של מקומות העבודה, ללא שמות | פעיל כל עוד לא הוזן מפתח OpenRouteService; הדפדפן פונה בנוסף ישירות ל-OSRM אם שרת Klacks אינו מחזיר מסלול | לא מתוכנן |
| OpenRouteService (`api.heigit.org`) | כמו OSRM, ובנוסף אופניים והליכה | קואורדינטות של מקומות העבודה, ללא שמות | רק עם מפתח API שהוזן | הסרת המפתח תחת הגדרות > OpenRoute |
| אריחי מפה (OpenStreetMap, OpenStreetMap.de או CARTO) | הצגת המפה בלוח הבקרה | מהדפדפן: כתובת IP ומקטע המפה המוצג | פעיל ברגע שהמפה מוצגת | אפשר לבחור ספק במפה, אך לא שרת אריחים משלכם |
| GitHub (`github.com`) ו-GitHub Container Registry (`ghcr.io`) | התקנה ועדכונים אוטומטיים: מניפסט הגרסה ותמונות Docker | בקשות הורדה רגילות, ללא נתוני תכנון | פעיל | — |
| Klacks Marketplace (`klacks-software.ch/store`) | חבילות שפה ומדינה | קוד מדינה, קוד חבילה או מונח חיפוש | בחיפוש חבילות ובטעינת פרופיל מדינה | ניתן להגדיר את הכתובת דרך `LanguagePlugins__MarketplaceUrl` |
| Hugging Face (`huggingface.co`) | הורדה חד-פעמית של מודלי החיפוש של Klacksy | ללא נתוני לקוחות (הורדת קבצים) | בצורך הראשון | — |
| Open-Meteo (`api.open-meteo.com`, `air-quality-api.open-meteo.com`) | הערת מזג אוויר ואיכות אוויר בווידג'ט הברכה, שאילתת מזג אוויר דרך Klacksy | קואורדינטות הדפדפן (אם אושרו) או של מיקום החברה | פעיל | `Assistant__Ambient__Enabled=false` מכבה רק את ההערה על איכות האוויר ועל חגים, לא את שאילתת מזג האוויר של הברכה |
| Nager.Date (`date.nager.at`) | הערת חגים בווידג'ט הברכה | קוד מדינה | פעיל | `Assistant__Ambient__Enabled=false` |
| ספקי AI בענן (למשל OpenAI, Anthropic, Google, DeepSeek) | Klacksy ופונקציות רקע מבוססות AI (למשל סיווג מיקומי קבוצות) | בקשות יחד עם ההקשר הנדרש להן מהנתונים שלכם | רק אם הוגדר מודל ענן | שימוש במודל מקומי |
| שירותי קול, חיפוש ותרגום (למשל Deepgram, Groq, AssemblyAI, Edge TTS, OpenAI TTS, ElevenLabs, Google Cloud TTS, DeepL, חיפוש באינטרנט) | קלט ופלט קולי, חיפוש באינטרנט, תרגום | אודיו או טקסט | רק אם משתמשים או מגדירים; זיהוי הדיבור בדפדפן פועל, בהתאם לדפדפן, דרך השירות המקוון שלו | אי שימוש בפונקציה |

המתגים בעמודה "כיבוי" הם משתני סביבה של הקונטיינר `klacks-api`; הזינו אותם ב-`docker-compose.yml` תחת `environment:` של שירות זה. הזנה בקובץ `.env` בלבד אינה מספיקה, כי השירות אינו קורא אותו כ-`env_file`.

עם מודל AI מקומי אף בקשה למודל השפה אינה מגיעה לספק AI חיצוני. לשאר השירותים בטבלה זו זה לא משנה דבר.
