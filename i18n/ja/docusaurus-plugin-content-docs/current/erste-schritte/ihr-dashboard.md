# あなたのダッシュボード: すべてを一目で

ダッシュボードはKlacksのスタートページで、事業運営の最も重要な指標を一目で表示します — ヘッダー左上のロゴをクリックすればいつでもアクセスできます。

## 仕組み

ダッシュボードは4つのセクションに分かれており、それぞれ個別に開閉できます(セクションの行をクリック)。右上には「すべて展開」「すべて折りたたむ」ボタンと、個々のセクションを選んで表示・非表示を切り替えるメニューがあります。ハンドル(取っ手)アイコンの部分をドラッグ&ドロップすると、セクションの並び順を変更できます — 表示・非表示と並び順はお使いのブラウザに記憶されます。該当する権限がない場合は、「拠点」セクションのみが表示されます。

- **概要:** 2つのドーナツグラフが並び、それぞれグループ(サブグループを含む)ごとに1つのパイ片を表示します。「グループ別顧客数」は各グループの顧客数を、「グループ別勤務数」は各グループに割り当てられた勤務数を示します。中央には合計数が表示され、その横に名称・値・パーセントの凡例が並びます。
- **カバー率と確定:** こちらも2つのドーナツグラフで、常に当月分を対象とし、あなたに表示権限のあるグループに限定されます。「グループ別カバー率」は各グループで計画された勤務スロットのうち何件が埋まっているかを、「グループ別確定率」は既に確定(封印)された勤務がいくつあるかを示します。
- **リソース:** 選択した年の人員稼働状況を、365日分の日次グラフとして表示します。バーと折れ線の読み方の詳細は、専用ページ[リソース・モニター](../optimieren/ressourcen-monitor.md)をご覧ください。
- **拠点:** すべてのアクティブな住所をクラスター化されたマーカーとして示す地図で、「都市別」と「グループ別」を切り替えられます(選択内容は記憶されます)。検索フィールドで特定の住所へズームでき、マーカーをクリックすると、従業員・外部従業員・顧客ごとの内訳とストリートビューへのリンクを含むポップアップが開きます。地図の下には、同じ数値を拠点またはグループ別にタイル表示したビューが並びます。

## 知っておくと良いこと

- 権限がない場合は「拠点」セクションのみが表示されます — 残り3つのセクションにはそれぞれ対応する権限が必要です。
- セクションの並び順と表示・非表示はブラウザ単位で保存され、ユーザーアカウント単位ではありません — 別の端末では、標準表示から再スタートします。
- 「カバー率と確定」の数値は常に当月を対象としており、期間を自由に選択することはできません。
- リソース・モニターにおける過剰配置と不足配置の解釈については、専用ページ[リソース・モニター](../optimieren/ressourcen-monitor.md)も参考にしてください。
