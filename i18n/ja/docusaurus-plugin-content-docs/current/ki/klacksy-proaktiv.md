# 自発的なチームメンバーとしてのKlacksy

Klacksyは、尋ねられるのを待ちません。1時間に1回、バックグラウンドで事業運営の状況を確認し、気づいたこと — 未充足の勤務、期限切れが近づく契約、期限超過の期間、不足しているマスタデータ — を知らせます。どこまで踏み込んでよいかは、Administratorが気づきの種類ごとに個別に設定します — 初期状態では報告のみを行い、自分から行動することは一切ありません。

[自律レベル](../einstellungen/klacksy-konfiguration/autonomie-stufen.md)とは混同しないでください: あちらは、**あなたが**チャットで何かを頼んだときに、Klacksyがどれだけの確認を必要とするかについての話です。こちらはその逆です — Klacksyが**頼まれてもいないのに**行うことについての話です。

## 仕組み

**気づきとは何か:** 気づきとは、Klacksyが自ら行った気づきです — 例えば「この勤務は3日後になってもまだ未充足です」や「この精算期間は1週間前から期限を超過しています」といったものです。そのために、1時間ごとにおよそ十数個の検査ルールにわたるバックグラウンド処理が実行されます。検知そのものはプログラムに固定されています: 何かが気づきに該当するかどうかを言語モデルが判断することはありません — 同じルールは、どのAIプロバイダーを使用していても同じ結果を返します。

**制御可能な気づきの種類は14あり**、そのうち未充足の勤務、空き状況の欠落、期限切れが近づく契約、マスタデータ不足、未封印の注文、期間締めの接近、期限超過の期間、所定時間からの乖離、空のコンテナ、ロック競合、未処理のシナリオが含まれます。このうち2種類は、毎時のバックグラウンド処理ではなく、ERP注文の取り込み時に発生します。

**3つのレベル — 気づきの種類ごとに個別設定:** 設定 > Klacksy > 「Klacksyの行動範囲」(エキスパートモード、Administrator限定)では、気づきの種類ごとに1行が用意され、「最大レベル」という列があります:

- **報告のみ** — Klacksyは知らせるだけで、それ以上のことはしません。これはすべての気づきの種類における初期設定です。
- **シナリオを準備** — Klacksyはさらに、人が承認するだけで済む完成済みの解決策をシナリオとして用意します。
- **実行** — Klacksyは気づきを自ら解消し、その後報告します。

「シナリオを準備」以上のレベルでは、責任者を指定する必要があります: その人の権限のもとで操作が実行され、その人に報告が届きます。これに加えて、各行にはKlacksyが行動できる回数を制限する予算(初期設定では1日あたり最大5回、60分以内では最大3回)と、「有効」の切り替えスイッチがあります。このスイッチが制御するのは自発的な行動のみです — 通知が届くかどうか、どう届くかは、あなた個人の通知設定のままです。

**プログラム内のハードな制限:** より高いレベルが働くのは、その気づきの種類に対して自動解消の仕組みがそもそも用意されている場合に限られます。用意されていなければ、設定にかかわらず、また個別にKlacksyに委任された場合でも、報告のみにとどまります。この制限はプログラムコードに組み込まれており、画面上から解除することはできません。現時点で自動解消が用意されているのはちょうど1件です: 気づきの種類「空のコンテナ」では、Klacksyが不足しているスロットテンプレートを自ら作成できます。

**気づきの届く場所:** ヘッダーのKlacksyボタンには、未読の通知件数がカウンターで表示されます。クリックするとサイドバーが開き、気づきは「あなたが離れている間に…」という見出しの下にまとめられています。各通知には「見せて」(該当箇所へジャンプ)、「役に立った」、「非表示にする」が用意されています — 「非表示にする」は理由を選んで(「このような通知は今後不要」「今回の通知は誤りだった」「すでに対応済み」)行うことも、理由なしで行うこともできます。許可されている場合には、さらに「あなたがやって」も表示されます: これは、この1件の気づきだけを「シナリオを準備」レベルに引き上げる個別許可です。チャットでKlacksyに、現在どんな気づきが未対応かを直接尋ねることもできます。

**気づきが解消されたとき:** 該当する行には、勤務リストのコンテナビュー上で「Klacksyにより…に解消済み」というマークが付きます — Klacksy自身が解消を実行した場合も、Klacksyが用意したシナリオを人が承認した場合も、どちらも同様です。Klacksy自身が実行した場合は、さらに責任者へ報告が送られます。

**緊急停止スイッチ:** チャットの上部には、Administrator向けに「Klacksyの自律行動: ON/OFF」のスイッチが表示されています。オフにすると、すべての気づきの種類が即座に「報告のみ」に戻ります — すでに与えられていた個別許可も含めてです。通知そのものは止まりません: 緊急停止が止めるのは行動であって、報告ではありません。同じスイッチは設定カードにもあります。

## 知っておくと良いこと

- 初期設定ではすべての気づきの種類が「報告のみ」です — Klacksyが行動するのは、Administratorが意図的にレベルを引き上げたときだけです。そのために緊急停止スイッチは必要ありません: 初期状態では作動しておらず、即座のブレーキとして予備に控えています。
- 通知はAdministratorと権限を持つPlannerにのみ届きます。特定のグループしか閲覧できない人には、そのグループの気づきだけが届きます。Administratorはすべてを見られます。Plannerは気づきを受け取りますが、レベル設定自体は見えません。
- 「シナリオを準備」レベルが機能するのは、シナリオとして表現できる解消策に限られます。現在用意されている解消策はこれに該当しません — この解消策には「実行」のみが働きます。
- 設定カードと自律スイッチにはAdministrator権限が必要です。権限がなければ、自律状態を確認することもできません。
- 1時間ごとのリズムは固定で組み込まれており、画面上から変更することはできません。最初の実行はプログラム起動の2分後に開始します。
