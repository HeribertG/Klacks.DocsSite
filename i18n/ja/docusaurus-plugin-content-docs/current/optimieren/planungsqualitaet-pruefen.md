# 計画品質を確認する: 違反・ギャップ・見送られた配置

計画アシスタントの実行後、Klacksは結果の横に3つの診断テーブルを表示します: プランがどこでルールに突き当たったか、どこで資格が不足しているか、そして何がそもそも計画されなかったかです。

## 仕組み

3つのレポートは、それぞれの計画アシスタントのダイアログに表示されます — プラン・グリッドの中にではありません。これらはアシスタント実行結果の一部であり、自動計画全体がAdminロールを前提としているため、Administratorにのみ表示されます。各レポートはタイトルに件数を表示し、**何も見つからなかった場合はそもそも表示されません** — 表示されないボックスは、つまり良い知らせです。

**ダイアログへのアクセス方法:** 勤務表にある魔法の杖ボタンは、初期状態ではダイアログを表示せず、直接計画の実行を開始します。**Ctrl+Shift+H** を押すと、Administratorはこのボタンを個々の計画アシスタント(Plan、Fuzzy Harmonizer、Holistic Harmonizer、Background Optimizer、Recovery)を選べるドロップダウンに切り替えられます — 診断テーブルを含むダイアログは、このドロップダウン経由でのみ開きます。

**資格ギャップ**は結果と一緒に表示されます。つまり、それを反映する*前*です。列: 重大度、シフト、日付、必要資格、理由 — さらに、少なくとも1行が特定の人物を挙げている場合には「従業員」列が加わります。理由には*未保有*、*期限切れ*、*レベル不足*のいずれかが表示されます。この背後には2つの異なるケースがあります: 対応可能な人の中に必要な資格を持つ人が誰もいなかったためにシフト枠が空いたままになったケース — この場合、行に人物名は表示されません。もう一つは、資格を満たしていない人がシフトに残っているケース — この場合は名前が表示されます。資格がシステム上に登録されていないだけなら、その人物にその資格を登録してください。[資格カタログ](../einstellungen/stammdaten-organisation/qualifikationen.md)に資格の管理方法が説明されています。そうでない場合は、別の人を割り当てるか、シフトの要件を調整してください。

**コンプライアンス違反**は、結果を反映した*後*に表示されます。列: 日付、従業員、コメント。コメントには、違反したルールと具体的な数値が平文で示されます。赤い行はエラー、黄色い行は警告・注意です。2つのハーモニー・アシスタントでは、レポートは新しいシナリオが実際のプランに対して**追加で**もたらす内容のみを示します — あわせて、そのうち何件がブロックモードで扱われる違反かも示されます。これらはシナリオが反映されるのを妨げます。修正されるか、権限を持つ人が明示的に上書きするまでの間です。

**見送られた配置**はシフト計画アシスタントでのみ発生し、こちらも反映した後に表示されます — 常に赤字です。列: 日付、従業員、シフト、理由。ここに書かれているのは、何が計画されたかではなく、Klacksが意図的に**書かなかった**ことです: ブロックモードで扱われるルールに違反していたはずの割り当てです。理由は短いカテゴリとして表示されます(「休息時間が短すぎる」「連続勤務日数が多すぎる」「時間の重複」など)。状況によっては、権限を持つ人に対し、Klacksはオーバーライドを使ってその実行結果をそれでも反映する選択肢を提示します。それ以外の人には、オーバーライドを有効にしてアシスタントをやり直すか、権限を持つ人に依頼するよう案内が表示されます。オーバーライドは必ず記録されます。

どのルールを検証し、どれだけ厳格に適用するかは[計画ルール](../planen/planungsregeln.md)で設定します。プランがそもそもどのように生成されるかは、[自動計画: ワンクリック、あとはバックグラウンド任せ](../planen/auto-planung.md)で説明しています。

## 知っておくと良いこと

- ブロックされたエントリーがあっても、プラン全体が破棄されるわけではありません: 影響を受けた割り当てだけが除外され、同じ人物の問題のないエントリーはそのまま書き込まれます。
- 資格ギャップの重大度には単純なルールがあります: 必須と指定された資格が完全に欠けている場合のみ**エラー**です。期限切れの資格、レベル不足、任意の要件はすべて**警告**として表示されます。
- 空いたシフト枠が資格ギャップに表示されるのは、本当に対応可能な人が誰もいなかった場合のみです。他の理由で空いたままになった場合は、通常の人員不足として扱われ、ここには表示されません。
- 自動計画が一括実行として通しで動いた場合、Klacksは結果を資格ギャップの件数を添えた短いポップアップとしてのみ通知します — 詳細なテーブルは、個々のアシスタントのダイアログに属するものです。
- レポートは純粋な閲覧専用です: 編集はできず、何かを変更することもありません。修正は[プラン・グリッド: あなたの対話型タイム・マトリックス](../planen/plan-raster.md)で行うか、再実行によって行います。
