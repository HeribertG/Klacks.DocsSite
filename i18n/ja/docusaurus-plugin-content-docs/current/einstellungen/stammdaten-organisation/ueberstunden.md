# 残業

設定 > コンプライアンスと割増ルール(エキスパートモード) > 残業では、累積時間が何時間に達すると残業が割増の対象になるか、また各段階の割増率をどの程度にするかを設定します。

## 仕組み

**計算基準:** 日次または週次 — それ以外はありません。月次や年次を基準にすることはできません。「週次」の場合、週の開始は設定された最初の曜日から始まります。

**最大3段階まで:** 各段階は2つの項目から成ります — 「第X段階 基準時間」(その段階が適用され始める、日または週の累積時間数)と、パーセントで表す「第X段階 割増率」です。設定されている中で最も高い段階には、上限がありません。

**各段階が数えるのは、その段階自身の範囲内の時間だけ**であり、ゼロからのすべての時間ではありません。第1段階が8時間から始まり、第2段階が10時間から始まる場合、10.5時間勤務した日は、8〜10時間の2時間分は第1段階の割増率で、それを超える30分だけが第2段階の割増率で計算されます — 10.5時間すべてに第2段階の割増率が適用されることはありません。このため、1つの勤務ブロックから、到達した段階の数だけ複数の割増項目が発生することがあります。

**不完全な段階は黙って読み飛ばされます:** 時間数の指定がない場合、または割増率がゼロ以下の場合、その段階はカウントされません。したがって、実際に有効な段階は0から3のいずれかになります。

**割増率は上乗せ分であり、総支給額ではありません:** 25%とは、その段階で働いた1時間ごとに4分の1時間分が追加で支給されることを意味し、その1時間が1.25倍で支払われるという意味ではありません。隣にある割増モード(倍率または時間当たり固定額)は単位を決めるだけで、その裏側の計算方法は変わりません。

**既に働いた時間として何がカウントされるか:** 各段階は、同じ日または同じ週にそれ以前に行われた勤務時間に基づいて埋まっていきます — まず日付順、次に開始時刻順に並べられます。こうして各勤務ブロックは範囲内の自分の位置を占め、同じ時間が二重により高い段階に計上されることはありません。以前のエントリーが変更されると、それ以降のエントリーは再計算されます。

**値の出所:** このカードは全社共通の値を提供します — これらの値が適用されるのは、他に優先される情報源がない場合に限られます。その人の契約に、独自の残業段階を持つ[計画ルール](../../planen/planungsregeln.md)が紐づけられている場合は、そちらが優先されます。該当日付に有効なこのルールの後続バージョンは、必要に応じてセット全体を置き換えますが、独自の残業ブロックを持たない場合は、計画ルールにではなく、ここに示された全社設定に戻ります。どこにも段階が設定されていない場合、最後のフォールバックとして働くのは計画ルールの**残業上限**のみです — しかもそれは第1段階の開始値としてのみであり、割増率としては決して使われません。情報源が混在することはありません: 第1段階を提供する情報源が、以降のすべての段階も提供します。

**割増が発生しない2つの条件:**

- 勤務には計算マクロが必要です。マクロのない勤務での労働は、残業のチェック対象に一切なりません。
- 少なくとも1つの完全な段階が設定されている必要があります。そのような段階がない場合、結果は「残業ゼロ」なのではなく、そもそもチェック自体が行われません。

**対象外:** 修正エントリーと代役出勤は、残業のチェック対象に一切なりません — 算入されるのは通常勤務のみです。

**他の割増との重複:** 同じ1時間が、残業と、夜間勤務や週末勤務といった状況に基づく割増の両方に該当することがあります。両方が加算されるのか、それとも高い方だけが適用されるのかは、このカードではなく、それぞれの勤務の計算マクロが決定します。

**保存:** このカードは設定ページの「コンプライアンスと割増ルール」セクションにあり(代替休息、割増モード、コンプライアンス施行と並んで)、エキスパートモードでのみ表示されます。変更はまとめて、設定ページ共通の保存バーを通じて保存または破棄されます — このカード自体に専用の保存ボタンはありません。

## 知っておくと良いこと

- このカードが扱うのは、日または週のしきい値に基づく自動的な残業段階のみです。夜間・日曜・祝日勤務の割増は、これとは別に汎用的なスクリプトによって計算されます — 詳しくは[マクロ](../klacksy-konfiguration/makros.md)を参照してください。
- 「基準時間」の値がない段階、または割増率が0%以下の段階は無視されます — こうすることで、個々の段階を削除せずに無効化できます。
- 少なくとも1つの完全な段階と、勤務への計算マクロの両方がなければ、どれほど長時間の勤務であっても残業割増は原則として発生しません。
- 独自の残業段階を持つ計画ルールは、この全社共通の値を個々の段階だけでなく、完全に上書きします。
