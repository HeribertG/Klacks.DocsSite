# 用語集

Klacksとこのドキュメントに繰り返し登場する用語を、出会う順に簡潔にまとめました。

## 計画

**従業員行**
計画できる最小の単位です。人でも日でもなく、特定のプランシートの中にある、ある人の行を指します。すべての計画値はこの行に紐づきます。

**プランシート**
従業員行への**参照**を集める入れ物です — コピーではありません。そのため、ある人が複数のサブプランに登場しても存在するのは一度だけで、変更はすぐにあらゆる場所に反映されます。[モジュール式計画](../planen/modulare-planung/)の土台です。

**自動計画**
アシスタントが、あなたのルールに従ってプランを埋めます。計算はバックグラウンドで実行されるので、その間も作業を続けられます — [自動計画](../planen/auto-planung/)を参照してください。

**空き状況**
ある人がいつ稼働可能かを示します — 時間単位または日単位で、自社の従業員にも外部の従業員にも対応します。[空き状況グリッド](../planen/verfuegbarkeits-raster/)を参照してください。

**注文(オーダー)**
まだ編集できる、勤務のスケッチです。注文は**まだ計画できません**。

**封印**
注文を計画可能な勤務に変える、一度きりの**元に戻せない**手順です。このとき、注文に対応する計画可能な側も同時に作られます。計画可能な勤務を直接作成する方法はKlacksにはありません — すべての勤務は封印によって生まれます。[勤務のライフサイクル](../planen/schicht-lebenszyklus/)を参照してください。

**勤務(シフト)**
計画可能な、封印済みの稼働です。「シフト」という言葉も同じものを指します。

**承認レベル(シフトプラン)**
シフトプランは、決まった順序で4つの状態を通ります: **下書き → 確認済み → 承認済み → 完了**。確認はログインしているどのアカウントでも行えます。承認できるのはSupervisorとAdminのみ、完了にできるのはAdminだけです。[承認ワークフロー](../planen/freigabe-workflow/)を参照してください。

**期間 / 期間締め**
精算の対象期間です(毎週、隔週、毎月、または任意。支払間隔で設定します)。締めることで期間が確定し、これはAdminだけに許されています — [期間締め](../planen/periodenabschluss/)を参照してください。

**欠勤 — 二つの意味、一つの言葉**
マスターデータの領域で「欠勤」とは**欠勤タイプのカタログ**(名前、色、標準の長さ、標準値)を指します。一方、カレンダー上のバーは、**希望**(計画された欠勤で、自由に動かせてロックレベルはありません)か、**登録済みの欠勤**(勤務計画から取り込まれたもので、欠勤ページでは閲覧のみ可能、ロックレベルあり)のどちらかです。この二つを取り違えると、探す場所を間違えます。

## AIアシスタント

**Klacksy**
KlacksのAIアシスタントです。計画し、説明し、実行します — モデルは自由に選べます。[Klacksy](../ki/klacksy-ki-assistent/)を参照してください。

**スキル**
Klacksyの、単独で完結した個別の能力です — 具体的なプログラムロジックを包む宣言的なラッパーで(「従業員を検索」「契約を割り当て」「レポートを作成」など)、Klacksyは実行時に適切なスキルを選びます。

**自律レベル**
Klacksyが確認なしでどこまで進めてよいかを表します:

| レベル | 名称 | 動作 |
|---|---|---|
| 0 | 提案のみ | 書き込みを伴う操作はすべてあなたの確認が必要 |
| 1 | アシスト | 元に戻せる操作は自由に実行。取り消せない操作や慎重を要する操作は確認する |
| 2 | 自律(標準) | 慎重を要する操作を除き、すべて自由に実行 |
| 3 | 完全自律 | 取り消せない手順も含めて実行 |

慎重を要する操作 — たとえばユーザーの削除や権限の変更 — は、**どのレベルでも**確認が入ります。[自律レベル](../einstellungen/klacksy-konfiguration/autonomie-stufen/)を参照してください。

## ロールと運用

**Admin / Supervisor / プランナー**
3つのアクセス段階です。Adminはすべてを行え、Supervisorは作成と編集ができ、ロールを持たないアカウントはプランナーです。一覧は[ロールと権限](../erste-schritte/rollen-und-rechte/)にあります。

**国別プロファイル**
国ごとにあらかじめ用意された設定一式です: 言語、タイムゾーン、祝日カレンダー、週末と週の開始日、労働時間の上限、休暇の付与日数、割増、標準の給与エクスポート、業種テンプレート。インストール時に`REGION`で選択します。

**Playground**
デモデータを入れた公開のテスト用インスタンスで、[play.klacks-software.ch](https://play.klacks-software.ch)にあります — 試すためのものであり、実在の個人データは入れません。[インストールとPlayground](../erste-schritte/installation-und-playground/)を参照してください。

**オンプレミス**
自社のインフラでの運用です: 自社のハードウェア、自社のデータベース、自社のデータ。ホスト型の対義語です。

**アップデートサービス**
署名付きアップデートを適用する、同梱のサービスです — 事前にバックアップを取り、問題があれば自動でロールバックします。[アップデートとロールバック](../betrieb/updates-und-rollback/)を参照してください。

**データ保護**
Klacksは外部へ通信して情報を送りません: データが開発元へ送り返されることはありません。実際に削除すべきデータについては、[データ保持](../einstellungen/system-sicherheit/datenaufbewahrung/)が対応します — 削除は期限の経過後に物理的に取り除かれます。
