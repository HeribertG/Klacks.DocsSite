# よくある質問

導入前に最もよく寄せられる質問に、正直にお答えします — 答えが「まだです」となる場合も含めて。

## 試す・始める

**Klacksを見るだけでも、インストールが必要ですか?**
いいえ。[Playground](https://play.klacks-software.ch)はデモデータ入りの公開インスタンスです。`admin@test.com` / `P@ssw0rt1`でログインすると、フル管理者権限が使えます。データベースは毎日スイス時間の04:00にリセットされます — 実在する個人データは入力しないでください。

**インストールにはどのくらい時間がかかりますか?**
インストーラーはコマンド1つです。パスワードと証明書を生成し、現在のバージョンを固定し、スタックを起動して、すべてが正常になるまで待ちます。いちばん時間がかかるのはイメージのダウンロードです。前提条件は[システム要件](../betrieb/systemvoraussetzungen/)に記載しています。

**なぜ自分用の管理者アカウントを作る必要があるのですか?**
同梱のアカウントのパスワードが公開されているからです。Klacksはそのアカウントでのログインを一度だけ許可し、その後はご自身のアカウントを求めます。その後、標準アカウントは無効になります。これは意図した動作であり、不具合ではありません。

## 運用

**データはどこにありますか?**
お客様のインフラ上にあります。Klacksがデータを開発元へ送り返すことはありません。AIモデルを外部サービスとして接続する場合、**そのサービス**にはもちろんそのサービスの規約が適用されます — モデルの選択はお客様次第です。

**クラウド事業者は必須ですか?**
いいえ、それがオンプレミスの核心です: スタックはお客様のサーバーで動きます。必要なのは、パッケージおよびアップデートの配布元(`ghcr.io`、`github.com`)への**外向きの**アクセスだけです。インターネットに一切接続しない運用は現時点では**ありません** — 隔離されたネットワークへのインストールは、まだ実装されていない今後の拡張段階です。

**データのバックアップはどうすればよいですか?**
ご自身で行います — バックアップはお客様の責任です。方法と、決して忘れてはならないボリュームについては、[バックアップと復元](../betrieb/backup-und-wiederherstellung/)をご覧ください。

**アップデートに失敗したらどうなりますか?**
アップデートサービスは事前にデータベースをバックアップし、新しいバージョンをまとめて切り替え、その後に正常性を確認します。新しいバージョンが正常でなければ、自動的にロールバックします。詳細は[アップデートとロールバック](../betrieb/updates-und-rollback/)にあります。

**手持ちのハードウェアでKlacksは動きますか?**
目安は**RAM 8 GB、4 vCPU**です。小さめのホスト向けには、メモリを解放する設定が文書化されています — その代償として、Klacksyへの次の質問が少し長くかかります。

**既存のIdentity Providerと併用できますか?**
はい。Klacksは、独自のアカウントを管理する代わりに、既存のIDプロバイダーに接続できます — [Identity Provider](../einstellungen/kommunikation-integration/identity-provider/)を参照してください。

## 機能

**Klacksはどの業種に向いていますか?**
シフト制・現場派遣型の事業向けに設計されています: 訪問介護(スピテックス)、病院、警備サービス、清掃・ハウスサービス、物流などです。

**画面は何語に対応していますか?**
ドキュメントは25言語で用意されています。ドイツ語、英語、フランス語、イタリア語、スペイン語、ポーランド語、日本語、中国語(簡体字と繁体字)、アラビア語、ヘブライ語などが含まれ、アラビア語とヘブライ語は右から左への読み方向にも対応しています。

**AIモデルを必ず決めなければなりませんか?**
プロバイダーとモデルはご自身で選び、切り替えることもできます。設定と確認の方法は、[LLMプロバイダーとモデル](../einstellungen/klacksy-konfiguration/llm-provider-und-modelle/)と[モデル接続テスト](../einstellungen/klacksy-konfiguration/modell-verbindungstest/)をご覧ください。

**Klacksはいくらですか?**
ソースコードはGNU Affero General Public License v3(AGPL-3.0)の下で公開されています — 読む、変更する、自分で運用することが許されています。変更版をネットワーク経由で他者に提供する場合は、そのユーザーにも変更したソースコードをAGPL-3.0の下で公開する必要があります。それ以上のこと(質問、意見交換、今後の開発)は、[DiscordのKlacksコミュニティ](https://discord.gg/YRP8p2abVC)と[公開ソースコードリポジトリ](https://github.com/HeribertG/Klacks.Api)を通じて行われます。

**Klacksは完成していますか?**
いいえ。そして、どこにも完成したとは書いていません。Klacksは構築の途上にありますが、公開の場で開発され、実際に運用されています — 説明を信じるのではなく、Playgroundでいつでも現在の状態をご自身で確かめられます。

## 協力する

**不具合を見つけた、または質問があります。**
[DiscordのKlacksコミュニティ](https://discord.gg/YRP8p2abVC)がいちばん早いです。ソフトウェアの不具合は[リポジトリ](https://github.com/HeribertG/Klacks.Api)に報告してください。次の情報があると助かります: バージョン、エラー直前の操作、ログの最後の数行 — [トラブルシューティング](../betrieb/fehlerbehebung/)を参照してください。

**自分でも貢献できますか?**
ソースコードは公開されており、ドキュメントも同じ場所にあります。分かりにくい箇所の指摘は、コードと同じように歓迎します。
