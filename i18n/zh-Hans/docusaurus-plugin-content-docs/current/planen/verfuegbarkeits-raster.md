# 可用性网格：谁何时有空

与其猜测谁在什么时候有空，不如把它记录下来：在可用性网格中，您可以为每一位员工按小时或按天精确登记这个人何时可以出勤 — 这里记录的不是客户的可用时间，而是自有员工与外部人员的可用时间。

## 运作方式

- **期间导航：** 箭头按钮可前后翻页切换期间，期间按钮会打开一个迷你日历，供您直接跳转。期间的长度 — 一周、两周或一个月 — 由所选分组的支付周期自动决定。
- **可选择的小时粒度：** 一个滑块可调节列的精细程度：1 小时、2 小时、4 小时、上午/下午或整天。点击一个较粗的单元格会同时设置其下属的所有小时。
- **带排序与筛选的行头：** 左侧的员工列表可按名字、姓氏、公司或合同保障工时排序，并可通过复选框限定为自有员工或外部人员；顶部栏的搜索框还可按姓名或编号筛选。
- **颜色编码：** 已设定的周末日和法定假日拥有各自的背景色，让非工作日一眼可辨。哪些星期几算作周末是可配置的 — 并非在所有地方都是星期六和星期日（例如安息日或其他因国家而异的休息日）。
- **鼠标或键盘操作：** 点击可切换一个单元格的状态，按住鼠标拖动可一次选中多个单元格；您也可以用方向键在网格中导航，并用空格键或回车键确认。
- **自动保存：** 没有保存按钮 — 改动会在最后一次输入后约 1 秒自动保存。

## 小贴士

- 没有任何标记的一天，对排班完全开放。一旦某天至少有一个小时被标记为可用，这一天就被视为已完整登记：只有被标记的小时可用于排班，这一天其余的所有小时都被锁定。
- 客户从不会出现在网格中 — 这里只显示在所示时间段内拥有会籍的自有员工与外部人员。
- 已登记的缺勤会完全覆盖可用性设置 — 即使勾选了可用，这一天也不会被排班。
- 登记的可用时间会直接汇入[自动排班：一键启动，后台运行](../planen/auto-planung.md)：算法只会在已报备的时间范围内排班。
