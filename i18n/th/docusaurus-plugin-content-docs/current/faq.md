# คำถามที่พบบ่อย

คำถามที่ถูกถามบ่อยที่สุดก่อนการใช้งานครั้งแรก — พร้อมคำตอบที่ตรงไปตรงมา แม้ในกรณีที่คำตอบคือ "ยังไม่มี"

## การลองใช้งานและการเริ่มต้น

**ฉันต้องติดตั้ง Klacks ก่อนจึงจะดูได้หรือไม่?**
ไม่ต้อง [Playground](https://play.klacks-software.ch) เป็นอินสแตนซ์สาธารณะที่มีข้อมูลตัวอย่าง คุณเข้าสู่ระบบด้วย `admin@test.com` / `P@ssw0rt1` และมีสิทธิ์ Admin เต็มรูปแบบ ฐานข้อมูลจะถูกรีเซ็ตทุกวันเวลา 04:00 น. ตามเวลาสวิตเซอร์แลนด์ — อย่าสร้างข้อมูลส่วนบุคคลจริงที่นั่น

**การติดตั้งใช้เวลานานแค่ไหน?**
ตัวติดตั้งคือคำสั่งเดียว มันสร้างรหัสผ่านและใบรับรอง ปักหมุดเวอร์ชันปัจจุบัน เริ่มสแต็ก และรอจนกว่าทุกอย่างจะทำงานเป็นปกติ เวลาส่วนใหญ่หมดไปกับการดาวน์โหลดอิมเมจ ข้อกำหนดเบื้องต้นอยู่ที่[ความต้องการของระบบ](../betrieb/systemvoraussetzungen/)

**ทำไมฉันต้องสร้างบัญชี Admin ของตัวเอง?**
เพราะบัญชีที่มาพร้อมระบบมีรหัสผ่านที่เป็นที่รู้จักของสาธารณะ Klacks ให้คุณเข้าสู่ระบบด้วยบัญชีนั้นได้เพียงครั้งเดียว แล้วจึงบังคับให้สร้างบัญชีของคุณเอง หลังจากนั้นบัญชีมาตรฐานจะถูกปิด นี่เป็นความตั้งใจ ไม่ใช่ข้อผิดพลาด

## การดูแลระบบ

**ข้อมูลของฉันอยู่ที่ไหน?**
บนโครงสร้างพื้นฐานของคุณ Klacks ไม่ส่งข้อมูลของคุณกลับไปยังผู้พัฒนา หากคุณเชื่อมต่อโมเดล AI เป็นบริการภายนอก เงื่อนไขของ**บริการนั้น**ย่อมมีผลบังคับใช้ — การเลือกโมเดลเป็นของคุณ

**ฉันจำเป็นต้องใช้ผู้ให้บริการคลาวด์หรือไม่?**
ไม่จำเป็น นั่นคือหัวใจของ On-Premise: สแต็กทำงานบนเซิร์ฟเวอร์ของคุณ คุณต้องการเพียงการเข้าถึง**ขาออก**ไปยังแหล่งแพ็กเกจและแหล่งอัปเดต (`ghcr.io`, `github.com`) ปัจจุบัน**ยังไม่มี**การใช้งานแบบไม่มีอินเทอร์เน็ตเลย — การติดตั้งในเครือข่ายที่แยกขาดเป็นขั้นตอนการพัฒนาต่อที่ยังไม่ได้ดำเนินการ

**ฉันจะสำรองข้อมูลได้อย่างไร?**
ด้วยตัวเอง — การสำรองข้อมูลเป็นความรับผิดชอบของคุณ วิธีการและวอลุ่มที่คุณห้ามลืมเด็ดขาดอยู่ที่[การสำรองข้อมูลและการกู้คืน](../betrieb/backup-und-wiederherstellung/)

**จะเกิดอะไรขึ้นถ้าการอัปเดตผิดพลาด?**
บริการอัปเดตจะสำรองฐานข้อมูลก่อน สลับเวอร์ชันใหม่พร้อมกัน แล้วตรวจสอบสถานะการทำงาน หากเวอร์ชันใหม่ไม่ปกติ ระบบจะย้อนกลับโดยอัตโนมัติ รายละเอียดอยู่ที่[การอัปเดตและการย้อนกลับ](../betrieb/updates-und-rollback/)

**Klacks ทำงานบนฮาร์ดแวร์ที่ฉันมีอยู่ได้หรือไม่?**
ค่าแนะนำโดยประมาณคือ **RAM 8 GB และ 4 vCPU** สำหรับโฮสต์ขนาดเล็กกว่านี้มีการตั้งค่าที่มีเอกสารกำกับซึ่งช่วยคืนหน่วยความจำ — โดยแลกกับการที่คำถามถัดไปที่ถาม Klacksy จะใช้เวลานานขึ้นเล็กน้อย

**Klacks ใช้งานร่วมกับ Identity Provider ของฉันได้หรือไม่?**
ได้ Klacks สามารถเชื่อมต่อกับผู้ให้บริการระบุตัวตนที่มีอยู่แล้ว แทนที่จะดูแลบัญชีเอง — ดู [Identity Provider](../einstellungen/kommunikation-integration/identity-provider/)

## ฟังก์ชัน

**Klacks เหมาะกับอุตสาหกรรมใด?**
ออกแบบมาสำหรับธุรกิจที่ทำงานเป็นกะและมีการปฏิบัติงานภาคสนาม: การพยาบาลผู้ป่วยนอกและ Spitex โรงพยาบาล บริการรักษาความปลอดภัย บริการทำความสะอาดและงานบ้าน รวมถึงโลจิสติกส์

**หน้าจอใช้งานรองรับภาษาอะไรบ้าง?**
เอกสารมีให้ใน 25 ภาษา ซึ่งรวมถึงเยอรมัน อังกฤษ ฝรั่งเศส อิตาลี สเปน โปแลนด์ ญี่ปุ่น จีน (ตัวย่อและตัวเต็ม) อาหรับ และฮีบรู — ภาษาอาหรับและฮีบรูรองรับทิศทางการอ่านจากขวาไปซ้ายด้วย

**ฉันต้องตัดสินใจเลือกโมเดล AI หรือไม่?**
คุณเลือกผู้ให้บริการและโมเดลเองและสามารถเปลี่ยนได้ วิธีตั้งค่าและตรวจสอบอยู่ที่[ผู้ให้บริการ LLM และโมเดล](../einstellungen/klacksy-konfiguration/llm-provider-und-modelle/) และ[ทดสอบการเชื่อมต่อโมเดล](../einstellungen/klacksy-konfiguration/modell-verbindungstest/)

**Klacks ราคาเท่าไหร่?**
ซอร์สโค้ดอยู่ภายใต้ GNU Affero General Public License v3 (AGPL-3.0) — คุณอ่าน แก้ไข และดำเนินการเองได้ หากคุณเสนอเวอร์ชันที่แก้ไขแล้วให้ผู้อื่นผ่านเครือข่าย คุณต้องเปิดเผยซอร์สโค้ดที่แก้ไขแล้วให้ผู้ใช้เหล่านั้นภายใต้ AGPL-3.0 เช่นกัน ทุกสิ่งที่เกินกว่านั้น (คำถาม การแลกเปลี่ยนความคิดเห็น การพัฒนาต่อยอด) ดำเนินการผ่าน[ชุมชน Klacks บน Discord](https://discord.gg/YRP8p2abVC) และ[คลังซอร์สโค้ดสาธารณะ](https://github.com/HeribertG/Klacks.Api)

**Klacks สมบูรณ์แล้วหรือยัง?**
ยังไม่สมบูรณ์ และไม่มีที่ไหนเขียนว่าสมบูรณ์ Klacks อยู่ระหว่างการสร้าง แต่พัฒนาอย่างเปิดเผยและมีการใช้งานจริง — ใน Playground คุณตรวจสอบสถานะปัจจุบันได้ด้วยตัวเองทุกเมื่อ แทนที่จะเชื่อคำบรรยาย

## ร่วมสนับสนุน

**ฉันพบข้อผิดพลาดหรือมีคำถาม**
เร็วที่สุดคือ[ชุมชนบน Discord](https://discord.gg/YRP8p2abVC) สำหรับข้อผิดพลาดในซอฟต์แวร์ ควรแจ้งไว้ใน[คลังซอร์สโค้ด](https://github.com/HeribertG/Klacks.Api) ข้อมูลที่ช่วยได้เสมอคือ เวอร์ชัน ขั้นตอนสุดท้ายก่อนเกิดข้อผิดพลาด และบรรทัดสุดท้ายของบันทึก — ดู[การแก้ไขปัญหา](../betrieb/fehlerbehebung/)

**ฉันช่วยสนับสนุนอะไรได้บ้างไหม?**
ซอร์สโค้ดเปิดเผย และเอกสารอยู่ในที่เดียวกัน ข้อสังเกตเกี่ยวกับจุดที่ไม่ชัดเจนยินดีต้อนรับไม่แพ้โค้ด
