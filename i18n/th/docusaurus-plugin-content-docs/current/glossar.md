# อภิธานศัพท์

คำศัพท์ที่พบซ้ำแล้วซ้ำอีกใน Klacks และในเอกสารนี้ — สรุปสั้น ๆ และเรียงตามลำดับที่คุณจะได้พบ

## การวางแผน

**แถวพนักงาน**
หน่วยที่เล็กที่สุดที่วางแผนได้ ไม่ใช่ตัวบุคคลและไม่ใช่วัน แต่คือแถวของบุคคลหนึ่งคนในแผ่นแผนงานที่เฉพาะเจาะจง ค่าการวางแผนทั้งหมดผูกอยู่กับแถวนี้

**แผ่นแผนงาน**
ที่เก็บรวบรวม**การอ้างอิง**ไปยังแถวพนักงาน — ไม่ใช่สำเนา ด้วยเหตุนี้บุคคลหนึ่งคนจึงมีอยู่เพียงครั้งเดียว ไม่ว่าจะปรากฏในแผนย่อยกี่แผน และการเปลี่ยนแปลงจะเห็นได้ทันทีในทุกที่ เป็นพื้นฐานของ[การวางแผนแบบโมดูลาร์](../planen/modulare-planung/)

**การวางแผนอัตโนมัติ**
ผู้ช่วยเติมแผนให้เต็มตามกฎของคุณ การคำนวณทำงานอยู่เบื้องหลังขณะที่คุณทำงานต่อได้ — ดู[การวางแผนอัตโนมัติ](../planen/auto-planung/)

**ความพร้อมทำงาน**
เวลาที่บุคคลหนึ่งพร้อมปฏิบัติงาน — ละเอียดถึงระดับชั่วโมงหรือวัน ทั้งพนักงานของบริษัทเองและพนักงานภายนอก ดู[กริดความพร้อมทำงาน](../planen/verfuegbarkeits-raster/)

**คำสั่งซื้อ (ใบสั่งงาน)**
ร่างของงานที่ต้องปฏิบัติซึ่งยังแก้ไขได้ คำสั่งซื้อ**ยังวางแผนไม่ได้**

**ปิดผนึก**
ขั้นตอนครั้งเดียวที่**ย้อนกลับไม่ได้** ซึ่งเปลี่ยนคำสั่งซื้อให้เป็นกะงานที่วางแผนได้ ในขณะเดียวกันก็จะเกิดคู่ที่วางแผนได้ของคำสั่งซื้อนั้นขึ้น ใน Klacks ไม่มีการสร้างกะงานที่วางแผนได้โดยตรง — ทุกกะงานเกิดจากการปิดผนึก ดู[วงจรชีวิตของกะงาน](../planen/schicht-lebenszyklus/)

**กะงาน (เวร)**
งานที่ปิดผนึกแล้วและวางแผนได้ คำว่า "เวร" มีความหมายเดียวกัน

**ระดับการอนุมัติ (ตารางเวรงาน)**
ตารางเวรงานผ่านสี่สถานะตามลำดับตายตัว: **ฉบับร่าง → ยืนยันแล้ว → อนุมัติแล้ว → ปิดผนึกแล้ว** บัญชีที่เข้าสู่ระบบทุกบัญชียืนยันได้ เฉพาะ Supervisor และ Admin เท่านั้นที่อนุมัติได้ และเฉพาะ Admin เท่านั้นที่ปิดได้ ดู[ขั้นตอนการอนุมัติ](../planen/freigabe-workflow/)

**งวด / การปิดงวด**
รอบระยะเวลาการเรียกเก็บ (รายสัปดาห์ ทุกสองสัปดาห์ รายเดือน หรือกำหนดเอง โดยกำหนดผ่านช่วงเวลาการชำระเงิน) การปิดงวดทำให้งวดนั้นมีผลผูกพันและสงวนไว้สำหรับ Admin — ดู[การปิดงวด](../planen/periodenabschluss/)

**การขาดงาน — สองสิ่ง หนึ่งคำ**
ในส่วนข้อมูลหลัก "การขาดงาน" หมายถึง**แคตตาล็อกประเภทการขาดงาน** (ชื่อ สี ความยาวเริ่มต้น ค่าเริ่มต้น) ส่วนแท่งในปฏิทินเป็นได้ทั้ง **คำขอ** (การขาดงานที่วางแผนไว้ ย้ายได้อย่างอิสระและไม่มีระดับการล็อก) หรือ **การขาดงานที่บันทึกแล้ว** (นำมาจากแผนการปฏิบัติงาน อ่านได้อย่างเดียวในหน้าการขาดงานและมีระดับการล็อก) ใครที่สับสนทั้งสองอย่างจะไปค้นหาผิดที่

## ผู้ช่วย AI

**Klacksy**
ผู้ช่วย AI ของ Klacks วางแผน อธิบาย และลงมือทำ — ด้วยโมเดลที่เลือกได้อย่างอิสระ ดู [Klacksy](../ki/klacksy-ki-assistent/)

**ทักษะ**
ความสามารถเดี่ยวที่มีขอบเขตชัดเจนของ Klacksy — ตัวห่อแบบประกาศ (declarative wrapper) รอบตรรกะโปรแกรมจริง ("ค้นหาพนักงาน" "กำหนดสัญญา" "สร้างรายงาน") Klacksy จะเลือกทักษะที่เหมาะสมขณะทำงาน

**ระดับความเป็นอิสระ**
Klacksy ลงมือทำได้ไกลเพียงใดโดยไม่ต้องถามก่อน:

| ระดับ | ชื่อ | พฤติกรรม |
|---|---|---|
| 0 | เสนอแนะ | ทุกการกระทำที่เขียนข้อมูลต้องได้รับการยืนยันจากคุณ |
| 1 | ผู้ช่วย | การกระทำที่ย้อนกลับได้ดำเนินการทันที ส่วนการกระทำที่เป็นที่สิ้นสุดและที่อ่อนไหวจะถามก่อน |
| 2 | อัตโนมัติ (ค่าเริ่มต้น) | ทุกอย่างดำเนินการทันที ยกเว้นการกระทำที่จัดว่าอ่อนไหว |
| 3 | อัตโนมัติเต็มรูปแบบ | แม้แต่ขั้นตอนที่เป็นที่สิ้นสุดก็ดำเนินการทันที |

การกระทำที่อ่อนไหว — เช่น การลบผู้ใช้หรือการเปลี่ยนสิทธิ์ — จะถามก่อนใน**ทุก**ระดับ ดู[ระดับความเป็นอิสระ](../einstellungen/klacksy-konfiguration/autonomie-stufen/)

## บทบาทและการดูแลระบบ

**Admin / Supervisor / ผู้วางแผน**
ระดับการเข้าถึงสามระดับ Admin ทำได้ทุกอย่าง Supervisor สร้างและแก้ไขได้ ส่วนบัญชีที่ไม่มีบทบาทคือผู้วางแผน ภาพรวมอยู่ที่[บทบาทและสิทธิ์การเข้าถึง](../erste-schritte/rollen-und-rechte/)

**โปรไฟล์ประเทศ**
ชุดการตั้งค่าที่เตรียมไว้สำหรับแต่ละประเทศ: ภาษา เขตเวลา ปฏิทินวันหยุด วันหยุดสุดสัปดาห์และวันเริ่มต้นสัปดาห์ ขีดจำกัดเวลาทำงาน สิทธิ์วันหยุดพักผ่อน ค่าตอบแทนเพิ่มเติม การส่งออกเงินเดือนเริ่มต้น และแม่แบบตามอุตสาหกรรม เลือกตอนติดตั้งผ่าน `REGION`

**Playground**
อินสแตนซ์ทดสอบสาธารณะที่ [play.klacks-software.ch](https://play.klacks-software.ch) พร้อมข้อมูลตัวอย่าง — มีไว้เพื่อลองใช้งานโดยเฉพาะ ไม่มีข้อมูลส่วนบุคคลจริง ดู[การติดตั้งและ Playground](../erste-schritte/installation-und-playground/)

**On-Premise**
การใช้งานบนโครงสร้างพื้นฐานของคุณเอง: ฮาร์ดแวร์ของคุณ ฐานข้อมูลของคุณ ข้อมูลของคุณ เป็นตรงข้ามกับรูปแบบที่โฮสต์ให้

**บริการอัปเดต**
บริการที่มาพร้อมกันซึ่งติดตั้งการอัปเดตที่มีลายเซ็น — โดยสำรองข้อมูลก่อน และย้อนกลับอัตโนมัติเมื่อมีปัญหา ดู[การอัปเดตและการย้อนกลับ](../betrieb/updates-und-rollback/)

**การคุ้มครองข้อมูล**
Klacks ไม่แอบส่งข้อมูลกลับไปยังต้นทาง: ไม่มีการส่งข้อมูลของคุณกลับไปยังผู้พัฒนา สำหรับข้อมูลที่ต้องถูกลบจริง ๆ นั้น [การเก็บรักษาข้อมูล](../einstellungen/system-sicherheit/datenaufbewahrung/) เป็นผู้ดูแล — รายการที่ถูกลบจะถูกลบออกทางกายภาพเมื่อสิ้นสุดระยะเวลาที่กำหนด
