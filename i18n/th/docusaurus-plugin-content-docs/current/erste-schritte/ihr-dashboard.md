# แดชบอร์ดของคุณ: มองเห็นทุกอย่างในพริบตาเดียว

แดชบอร์ดคือหน้าแรกของ Klacks และแสดงตัวชี้วัดที่สำคัญที่สุดของกิจการให้เห็นในพริบตาเดียว — เข้าถึงได้ด้วยการคลิกที่โลโก้มุมซ้ายบนของส่วนหัว

## วิธีการทำงาน

แดชบอร์ดแบ่งออกเป็นสี่ส่วนที่พับเก็บและขยายได้ทีละส่วน (คลิกที่แถบหัวข้อของส่วนนั้น) มุมขวาบนมีปุ่มสำหรับขยายทั้งหมดหรือพับเก็บทั้งหมด รวมถึงเมนูสำหรับเลือกซ่อน/แสดงแต่ละส่วนเป็นรายบุคคล ที่ไอคอนแฮนเดิลสามารถลากแล้ววาง (Drag & Drop) เพื่อจัดลำดับส่วนใหม่ได้ — เบราว์เซอร์ของคุณจะจดจำการมองเห็นและลำดับไว้ให้ หากไม่มีสิทธิ์ที่เกี่ยวข้อง จะมองเห็นเฉพาะส่วน "สถานที่" เท่านั้น

- **ภาพรวม:** แผนภูมิโดนัทสองอันเรียงข้างกัน แต่ละชิ้นส่วนแทนหนึ่งกลุ่ม (รวมกลุ่มย่อยด้วย) "ลูกค้าตามกลุ่ม" แสดงจำนวนลูกค้าของแต่ละกลุ่ม ส่วน "กะงานตามกลุ่ม" แสดงจำนวนกะงานที่กำหนดให้แต่ละกลุ่ม ตรงกลางแสดงจำนวนรวม ข้าง ๆ มีคำอธิบายสัญลักษณ์แจ้งชื่อ ค่า และเปอร์เซ็นต์
- **ความครอบคลุมและการยืนยัน:** เป็นแผนภูมิโดนัทสองอันเช่นกัน แสดงผลของเดือนตามปฏิทินปัจจุบันเสมอ และจำกัดเฉพาะกลุ่มที่คุณมองเห็นได้ "ความครอบคลุมตามกลุ่ม" แสดงต่อกลุ่มว่าสล็อตกะงานที่วางแผนไว้ในเดือนนั้นมีคนประจำแล้วกี่ตำแหน่ง ส่วน "ยืนยันแล้วตามกลุ่ม" แสดงว่ามีการปฏิบัติงานกี่ครั้งที่ได้รับการยืนยัน (ปิดผนึก) แล้ว
- **ทรัพยากร:** แสดงการใช้กำลังคนของปีที่เลือกเป็นแผนภูมิรายวันตลอด 365 วัน รายละเอียดวิธีอ่านแท่งและเส้นดูได้ที่หน้า [ตัวติดตามทรัพยากร](../optimieren/ressourcen-monitor.md) โดยเฉพาะ
- **สถานที่:** แผนที่แสดงที่อยู่ที่ใช้งานอยู่ทั้งหมดเป็นหมุดแบบรวมกลุ่ม สลับได้ระหว่าง "ตามเมือง" และ "ตามกลุ่ม" (ระบบจดจำตัวเลือกไว้) มีช่องค้นหาช่วยซูมไปยังที่อยู่หนึ่ง ๆ คลิกที่หมุดจะเปิดป็อปอัพแสดงรายละเอียดแยกตามพนักงาน พนักงานภายนอก และลูกค้า พร้อมลิงก์ Street View ใต้แผนที่มีมุมมองแบบการ์ดแสดงตัวเลขเดียวกันแยกตามสถานที่หรือกลุ่ม

## ข้อมูลที่ควรทราบ

- หากไม่มีสิทธิ์ คุณจะเห็นเฉพาะส่วน "สถานที่" — สามส่วนที่เหลือต้องมีสิทธิ์ที่เกี่ยวข้อง
- ลำดับและการมองเห็นของแต่ละส่วนถูกบันทึกไว้ต่อเบราว์เซอร์ ไม่ใช่ต่อบัญชีผู้ใช้ — บนอุปกรณ์อื่นคุณจะเริ่มต้นด้วยมุมมองมาตรฐานอีกครั้ง
- ตัวเลขใน "ความครอบคลุมและการยืนยัน" อ้างอิงถึงเดือนปัจจุบันเสมอ ไม่มีช่วงเวลาที่เลือกได้อย่างอิสระ
- สำหรับการตีความการครอบคลุมเกินหรือครอบคลุมไม่พอในตัวติดตามทรัพยากร ควรดูที่หน้า [ตัวติดตามทรัพยากร](../optimieren/ressourcen-monitor.md) โดยเฉพาะ
