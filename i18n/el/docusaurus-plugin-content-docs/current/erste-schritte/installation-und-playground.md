# Εγκατάσταση και Playground

Το Klacks το δοκιμάζετε σε ένα λεπτό — και το εγκαθιστάτε σε λίγα λεπτά. Χωρίς εγγραφή, χωρίς συζητήσεις πωλήσεων.

## Playground: ο χώρος δοκιμών για εξοικείωση

Το Playground δεν είναι παραλλαγή εγκατάστασης, αλλά ένα δημόσιο διαθέσιμο στιγμιότυπο του Klacks με δείγματα δεδομένων για ελεύθερο πειραματισμό χωρίς δέσμευση — εξ ου και το όνομα. Τρέχει στο **[klacks-software.ch](https://play.klacks-software.ch)**:

- **Σύνδεση:** `admin@test.com` · **Κωδικός:** `P@ssw0rt1`
- Έχετε πλήρη δικαιώματα διαχειριστή — δοκιμάστε τα πάντα.
- Όλα τα δεδομένα **επαναφέρονται αυτόματα κάθε μέρα**. Μην εισάγετε πραγματικά προσωπικά δεδομένα.

## Εγκατάσταση: Στον δικό σας διακομιστή (On-Premise)

Το πακέτο On-Premise περιλαμβάνει τα πάντα: εικόνες Docker, πρόγραμμα εγκατάστασης, βάση δεδομένων, HTTPS και αυτόματες ενημερώσεις. Αυτό το πακέτο διατίθεται αποκλειστικά στο [Klacks Store](https://klacks-software.ch/store/?culture=el).

Στο Klacks Store επιλέξτε, αν θέλετε, τον κλάδο σας, κατεβάστε το ZIP για τη χώρα σας και αποσυμπιέστε το στο μηχάνημα προορισμού. Επιλέξτε έναν φάκελο που παραμένει στη θέση του (για παράδειγμα `~/klacks`): οι αυτόματες ενημερώσεις λειτουργούν με αυτόν τον φάκελο.

```bash
unzip 'klacks-onprem-*.zip' -d ~/klacks && cd ~/klacks && sudo bash ./install-*.sh
```

Σε Windows: `install-*.ps1` αντί για `install-*.sh`. Το πρόγραμμα εγκατάστασης δημιουργεί μόνο του κωδικούς και πιστοποιητικά, κατεβάζει τις τρέχουσες εικόνες Docker και περιμένει μέχρι όλα να λειτουργήσουν. Πρώτη σύνδεση με `admin@test.com` / `P@ssw0rt1` — **αλλάξτε αυτόν τον κωδικό αμέσως μετά την πρώτη σύνδεση.**

## Υπολογιστής γραφείου με Windows: και στο Microsoft Store

Για έναν μεμονωμένο υπολογιστή γραφείου με Windows υπάρχει ξεχωριστό πρόγραμμα εγκατάστασης που λειτουργεί χωρίς Docker. Το βρίσκετε στο [Klacks Store](https://klacks-software.ch/store/?culture=el) στη σελίδα της χώρας σας, καθώς και στο [Microsoft Store](https://apps.microsoft.com/store/detail/XPFFW8HDX0KX26) (καταχώριση «Klacks»). Και στα δύο καταστήματα πρόκειται για το ίδιο πρόγραμμα εγκατάστασης. Από το Microsoft Store εφαρμόζει τη χώρα που έχει οριστεί στα Windows· εκεί δεν επιλέγετε κλάδο, και αν δεν υπάρχει προφίλ για τη χώρα αυτή, η εγκατάσταση δεν ρυθμίζει κανένα. Οι εγκαταστάσεις σε διακομιστή, Docker και Linux, καθώς και τα πακέτα ανά χώρα και ανά κλάδο, διατίθενται μόνο στο Klacks Store.

Στον υπολογιστή γραφείου οι νέες εκδόσεις έρχονται μέσω Ρυθμίσεις > [Ενημερώσεις λογισμικού](../einstellungen/system-sicherheit/updates.md) στο Klacks, ακόμη κι αν το Klacks εγκαταστάθηκε από το Microsoft Store. Ένα νεότερο πρόγραμμα εγκατάστασης δεν μπορεί να εγκατασταθεί πάνω σε μια υπάρχουσα εγκατάσταση.

## Καλό να το ξέρετε

- Μια ενσωματωμένη υπηρεσία ενημερώσεων διατηρεί την εγκατάστασή σας αυτόματα ενημερωμένη — με αντίγραφο ασφαλείας πριν από κάθε ενημέρωση και αυτόματη επαναφορά σε περίπτωση προβλήματος.
- Τα δεδομένα σας παραμένουν εξ ολοκλήρου στη δική σας υποδομή· το Klacks δεν επικοινωνεί προς τα έξω.
- Προϋπόθεση είναι ένας διακομιστής με Docker, εξερχόμενη πρόσβαση στο διαδίκτυο (για εικόνες Docker και ενημερώσεις) και ανοιχτές θύρες 80/443.
