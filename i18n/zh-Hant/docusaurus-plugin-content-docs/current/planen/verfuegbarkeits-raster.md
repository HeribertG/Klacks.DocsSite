# 可用時間網格：誰在何時有空

與其猜測誰在什麼時候能夠出勤，不如直接記錄下來：在可用時間網格中，您可以為每一位員工精確記錄到小時或到天，標示這個人何時有空 — 記錄的不是客戶的可用時間，而是您自有員工與外部員工的可用時間。

## 運作方式

- **期間導覽：** 箭頭按鈕可前後翻頁切換期間，期間按鈕則會開啟一個迷你日曆，方便直接跳轉。期間的長度 — 週、雙週或月 — 由所選群組的給付週期自動決定。
- **可調整的時數精細度：** 滑桿可設定欄位的精細程度：1 小時、2 小時、4 小時、上午／下午或整天。點選較粗的儲存格，會一併設定其下所有的小時。
- **可排序與篩選的行首：** 左側的員工清單可依名字、姓氏、公司或合約保障工時排序，並可用核取方塊限定為自有員工或外部員工；頁首的搜尋欄位還能依姓名或編號篩選。
- **色彩標示：** 已設定的週末日與假日各有專屬的背景色，讓休息日一眼可辨。哪些星期幾算作週末是可以設定的 — 並非所有地方都是星期六與星期日（例如安息日或其他各國特有的休息日）。
- **滑鼠或鍵盤操作：** 點一下即可切換儲存格狀態，按住滑鼠拖曳可一次標記多個儲存格；也可以用方向鍵在網格中導覽，並以空白鍵或 Enter 鍵確認。
- **自動儲存：** 沒有儲存按鈕 — 異動會在最後一次輸入後約一秒自動儲存。

## 小提醒

- 完全沒有標記的一天，對排班而言仍是完全開放的。只要某一天至少有一個小時被標記為有空，這一天就視為已完整記錄：僅標記的時段可供排班使用，該天其餘所有時段都會被鎖定。
- 客戶永遠不會出現在網格中 — 顯示的僅限於在所示時間範圍內具有會員資格的自有與外部員工。
- 已登錄的缺勤會完全覆蓋可用時間 — 即使勾選標記，該天也不會被排班。
- 已記錄的可用時間會直接匯入[自動排班：一鍵啟動，其餘在背景執行](../planen/auto-planung.md)：演算法只會在回報的時段內排班。
