# 升級與待命

有人臨時無法出勤，而班次再過幾個小時就要開始。這時 Klacks 不會亂槍打鳥地叫醒整個團隊，而是依照事先設定好的升級聯絡清單，一位接一位地聯絡，直到有人接手為止。

## 運作方式

- **升級鏈會在補齊缺勤人力時觸發**：對於缺勤者原本有排班的每一個受影響日期，Klacks 都會建立一個獨立的升級，並關聯到那個確切的班次（參見[缺勤一目了然](./absenzen-im-blick.md)）。
- **升級聯絡清單只需設定一次**：在「設定 > 升級聯絡清單」中，列出所有具備群組可見性且已登錄電話號碼的使用者。順序由您以拖放方式決定，會立即儲存 — 整個機構共用同一份順序。
- **實際會聯絡到誰，要到事發當下才會決定**：Klacks 會從您設定的順序中，篩選出對該上層群組具有可見性的人員，跳過目前已登記為缺勤的人，並將管理員附加在名單最後，作為最後防線。
- **通知會透過多種管道發送**：詢問一律會出現在 Klacks 的收件匣中，已登入的使用者會立即在應用程式中看到，此外還會透過已串接的通訊軟體發送 — 畢竟凌晨三點不會有人坐在瀏覽器前面。通訊軟體串接與升級鏈的自動遞補，皆依安裝實例個別啟用。
- **一句話就能確認接手**：目前被詢問的人只需在通訊軟體中簡短回覆（「我來」）；管理員也可以改用*進行中的升級*頁面上的*接手*功能。之後，確認接手的人會收到一則確認訊息，先前已被詢問過的人則會收到一則靜默通知 — 沒有人會被第二次叫醒。

## 小提醒

- 期限指的並不是班次開始的那一刻，而是在此之前的一段前置時間（預設為兩小時）— 這樣接手的人才有時間動身前往。
- 每個階段可用的時間，由 Klacks 根據剩餘的期限計算出來：班次越接近，每一輪的時間就越短。如果時間已經緊迫到不足以依序詢問，Klacks 會同時詢問所有剩餘人選。
- 在*進行中的升級*頁面上，您可以看到每個階段的狀態 — 等待中、已詢問、已接手、無回應、已跳過或已取消。只要有升級正在進行，頁首還會額外顯示一個警告圖示。
- 升級聯絡清單與總覽頁面僅限管理員使用（參見[角色與權限](../erste-schritte/rollen-und-rechte.md)）。管理員可以中止正在進行的升級 — 但必須填寫理由，以便日後仍能追溯升級鏈被停止的原因。
- 使用者帳號中若沒有登錄電話號碼，就根本不會出現在升級聯絡清單中。透過通訊軟體發送詢問，還需要額外綁定通訊軟體聯絡人。待命人員的缺勤，可以直接在同一份清單中維護：起訖日期、可選填原因，也可以設定為永久有效。
