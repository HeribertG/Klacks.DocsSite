# 您的儀表板：一覽無遺

儀表板是 Klacks 的首頁，讓您一眼掌握營運的重要指標 — 點選頁首左上角的商標即可進入。

## 運作方式

儀表板分為四個區塊，各自可以獨立展開與收合（點選區塊列即可）。右上角提供「全部展開」與「全部收合」按鈕，以及一個可個別顯示／隱藏各區塊的選單。透過拖曳把手圖示，可用拖放方式重新排列區塊順序 — 顯示狀態與順序會由您的瀏覽器記住。若無相應權限，只有「地點」區塊可見。

- **總覽：** 並排兩個環圈圖，每個群組（含子群組）各佔一個扇形。「依群組分類的客戶數」顯示每個群組擁有多少客戶，「依群組分類的班次數」顯示每個群組配置了多少班次。中央顯示總數，旁邊搭配名稱、數值與百分比的圖例。
- **覆蓋率與確認：** 同樣是兩個環圈圖，固定顯示當月（目前的日曆月），並僅限於您可見的群組。「依群組分類的覆蓋率」顯示每個群組在當月已排定的班次時段中，有多少已被填補；「依群組分類的已確認數」顯示已有多少任務被確認（封存）。
- **資源：** 以 365 天的每日圖表，呈現所選年度的人力使用狀況。長條與線條的詳細解讀方式，請參閱獨立頁面[資源監控](../optimieren/ressourcen-monitor.md)。
- **地點：** 一張地圖，以群集標記顯示所有使用中的地址，可在「依城市」與「依群組」之間切換（選擇會被記住）。搜尋欄位可協助您縮放至特定地址，點選標記會開啟彈出視窗，依員工、外部員工與客戶分類列出明細，並附上街景連結。地圖下方的方塊檢視則以相同數字，依地點或群組列出清單。

## 小提醒

- 若無權限，您只會看到「地點」區塊 — 其餘三個區塊都需要相應的權限。
- 各區塊的順序與顯示狀態依瀏覽器儲存，並非依使用者帳號 — 換一台裝置時，您會重新以預設檢視啟動。
- 「覆蓋率與確認」的數字永遠只對應當月，沒有可自由選擇的時間範圍。
- 若要判讀資源監控中的過度配置與配置不足，值得參閱獨立的[資源監控](../optimieren/ressourcen-monitor.md)頁面。
