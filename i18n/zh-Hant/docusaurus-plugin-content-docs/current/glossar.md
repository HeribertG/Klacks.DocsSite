# 詞彙表

Klacks 與本文件中反覆出現的名詞 — 簡短說明，並依您遇到的先後順序排列。

## 排班

**員工列**
最小的可排班單位。不是人，也不是日期，而是某位人員在特定排班表中的那一列。所有排班數值都附屬於這一列。

**排班表**
一個收集員工列**參照**的容器 — 不是複本。因此，無論一個人出現在多少份子排班表中，他都只存在一次，而且任何變更都會立即在各處可見。這是[模組化排班](../planen/modulare-planung/)的基礎。

**自動排班**
由助手依照您的規則填滿排班表。運算在背景執行，您可以繼續其他工作 — 請參閱[自動排班](../planen/auto-planung/)。

**可用時間**
一個人何時可以投入工作 — 精確到小時或日，適用於內部與外部人員。請參閱[可用時間網格](../planen/verfuegbarkeits-raster/)。

**訂單（委託）**
一個仍可編輯的任務草案。訂單**尚無法排班**。

**封存**
將訂單轉為可排班班次的一次性、**不可逆**步驟。此時會同時產生訂單對應的可排班副本。在 Klacks 中無法直接建立可排班班次 — 每個班次都是透過封存產生的。請參閱[班次的生命週期](../planen/schicht-lebenszyklus/)。

**班次（輪班）**
可排班、已封存的任務。「輪班」一詞所指相同。

**核准階段（班次排班表）**
班次排班表會依固定順序經歷四種狀態：**開放 → 已確認 → 已核准 → 已結案**。任何已登入的帳號都可以確認；核准僅限主管與管理員；結案則僅限管理員。請參閱[核准流程](../planen/freigabe-workflow/)。

**期間／期間結算**
結算區間（每週、每兩週、每月或自訂；由給付週期決定）。結算會使一個期間具有約束力，並且僅限管理員執行 — 請參閱[期間結算](../planen/periodenabschluss/)。

**缺勤 — 兩件事，同一個詞**
在主檔資料區，「缺勤」指的是**缺勤類型目錄**（名稱、顏色、預設長度、預設值）。而日曆中的長條則是**願望**（計畫中的缺勤，可自由移動且沒有鎖定等級），或是**已登記缺勤**（取自排班計畫，在缺勤頁面中僅供檢視，並具有鎖定等級）。把兩者搞混的人，會找錯地方。

## AI 助手

**Klacksy**
Klacks 的 AI 助手。它負責排班、說明與執行 — 模型可自由選擇。請參閱 [Klacksy](../ki/klacksy-ki-assistent/)。

**技能**
Klacksy 的單項、界線明確的能力 — 是對具體程式邏輯的宣告式封裝（「搜尋員工」、「指派合約」、「產生報表」）。Klacksy 會在執行時選擇合適的技能。

**自主等級**
Klacksy 在不詢問的情況下可以走多遠：

| 等級 | 名稱 | 行為 |
|---|---|---|
| 0 | 建議 | 每項寫入動作都需要您確認 |
| 1 | 輔助 | 可復原的動作直接執行；不可復原與敏感的動作會先詢問 |
| 2 | 自主（預設） | 除了被歸類為敏感的動作外，其餘一律直接執行 |
| 3 | 完全自主 | 連不可復原的步驟也會直接執行 |

敏感動作 — 例如刪除使用者或變更權限 — 在**任何**等級都會先詢問。請參閱[自主等級](../einstellungen/klacksy-konfiguration/autonomie-stufen/)。

## 角色與營運

**管理員／主管／排班人員**
三個存取等級。管理員可執行所有操作，主管可建立與編輯，沒有角色的帳號即為排班人員。總覽請見[角色與權限](../erste-schritte/rollen-und-rechte/)。

**國家設定檔**
為特定國家預先準備好的一組設定：語言、時區、假日日曆、週末與每週起始日、工時上限、休假額度、加給、預設薪資匯出，以及產業範本。安裝時透過 `REGION` 選擇。

**Playground**
公開的測試實例，網址為 [play.klacks-software.ch](https://play.klacks-software.ch)，內含示範資料 — 明確用於試用，請勿輸入真實的個人資料。請參閱[安裝與 Playground](../erste-schritte/installation-und-playground/)。

**On-Premise**
在您自己的基礎設施上營運：您的硬體、您的資料庫、您的資料。與託管版本相對。

**更新服務**
隨附的服務，負責套用已簽署的更新 — 更新前先備份，遇到問題時自動回復。請參閱[更新與回復](../betrieb/updates-und-rollback/)。

**角色與資料保護**
Klacks 不會「打電話回家」：您的資料不會回傳給開發商。對於確實需要刪除的資料，由[資料保留](../einstellungen/system-sicherheit/datenaufbewahrung/)負責 — 刪除的資料在期限屆滿後會被實體移除。
